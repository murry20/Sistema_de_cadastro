# Visão geral do projeto

## Sobre

Sistema de cadastro é um projeto Java simples que permite cadastrar itens ou usuários via terminal. O projeto também inclui um script Python `revisao.py` para revisão ou testes adicionais.

## Estrutura de arquivos

- `Sistema_de_cadastro.java` — código principal do sistema.
- `revisao.py` — script auxiliar em Python.
- `.gitignore` — define arquivos a serem ignorados pelo Git.
- `LICENSE` — licença MIT.
- `README.md` — instruções de uso e visão geral do projeto.
- `CONTRIBUTING.md` — orientações para contribuições.
- `CHANGELOG.md` — histórico de mudanças do projeto.

## Como funciona

1. Compile o Java:
   ```bash
   javac Sistema_de_cadastro.java
   ```
2. Execute o sistema:
   ```bash
   java Sistema_de_cadastro
   ```

## Como contribuir

- Abra uma issue antes de implementar mudanças maiores.
- Crie uma branch separada para cada correção ou nova funcionalidade.
- Mantenha o código legível e documentado.
