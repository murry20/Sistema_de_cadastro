## 📁 Estrutura do projeto

- Sistema_de_cadastro.java - implementação principal em Java
- evisao.py - script Python auxiliar para revisão ou testes adicionais
- .gitignore - arquivos e pastas que não devem ser enviados ao Git
- LICENSE - licença MIT do projeto
- CONTRIBUTING.md - orientações para contribuir
- CODE_OF_CONDUCT.md - regras de convivência da comunidade
- CHANGELOG.md - histórico de alterações
- docs/overview.md - visão geral do projeto e uso
- .github/ISSUE_TEMPLATE/bug_report.md - modelo para bugs
- .github/ISSUE_TEMPLATE/feature_request.md - modelo para solicitações
- .github/PULL_REQUEST_TEMPLATE.md - modelo para pull requests

## 🚀 Como usar

1. Abra o projeto em sua IDE Java ou em um terminal.
2. Compile o arquivo Java:
   `ash
   javac Sistema_de_cadastro.java
   `
3. Execute o sistema:
   `ash
   java Sistema_de_cadastro
   `

> Se o projeto gerar arquivos .class, eles serão ignorados pelo Git graças ao .gitignore.

## 💡 Exemplos

- Para compilar e executar em sequência:
  `ash
  javac Sistema_de_cadastro.java
  java Sistema_de_cadastro
  `
- Se o Java estiver instalado corretamente, o sistema deve iniciar o fluxo de cadastro direto no terminal.

## 🧪 Requisitos

- Python instalado se você quiser executar evisao.py
