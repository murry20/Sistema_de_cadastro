# Sistema de cadastro

Projeto em Java com um sistema de cadastro simples e um arquivo Python de revisão.

## 📁 Estrutura do projeto

- `Sistema_de_cadastro.java` - implementação principal em Java
- `revisao.py` - script Python auxiliar para revisão ou testes adicionais
- `.gitignore` - arquivos e pastas que não devem ser enviados ao Git
- `LICENSE` - licença MIT do projeto

## 🚀 Como usar

1. Abra o projeto em sua IDE Java ou em um terminal.
2. Compile o arquivo Java:
   ```bash
   javac Sistema_de_cadastro.java
   ```
3. Execute o sistema:
   ```bash
   java Sistema_de_cadastro
   ```

> Se o projeto gerar arquivos `.class`, eles serão ignorados pelo Git graças ao `.gitignore`.

## 🧪 Requisitos

- Java JDK instalado (versão 8 ou superior)
- Python instalado se você quiser executar `revisao.py`
