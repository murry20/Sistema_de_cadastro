# Sistema de cadastro

Projeto em Java com um sistema de cadastro de usuários/itens, acompanhado de um arquivo Python `revisao.py`.

## Estrutura

- `Sistema_de_cadastro.java` - implementação do sistema principal em Java
- `revisao.py` - arquivo Python com revisões ou exemplos adicionais

## Como usar

1. Abra o projeto em sua IDE Java ou editor de texto.
2. Compile `Sistema_de_cadastro.java` com `javac Sistema_de_cadastro.java`.
3. Execute com `java Sistema_de_cadastro`.
